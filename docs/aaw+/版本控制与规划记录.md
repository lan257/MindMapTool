#### V0.2.0 
##### 数据库搭建
+ node 节点表

| 字段          | 类型       | 备注             |
| ----------- | -------- | -------------- |
| node_id     | int      | 主键，自动生成        |
| parent_id   | int      | 父节点的主键         |
| map_id      | int      | 外键，从属的思维导图     |
| create_time | datetime | 创建时间,自动生成      |
| change_time | datetime | 每次修改都更新，同样自动生成 |
| title       | text     | 标题             |
| content     | text     | 内容             |
| status      | int      | 状态             |
| user_id     | int      | 从属用户id（可选）     |
| love        | int      | 喜欢,默认为0        |
| comment     | text     | 批注，（可选）        |

+ mind_map 思维导图表

| 字段          | 类型       | 备注             |
| ----------- | -------- | -------------- |
| map_id      | int      | 主键，自动生成        |
| title       | text     | 标题             |
| content     | text     | 内容             |
| status      | int      | 状态             |
| user_id     | int      | 从属用户id（可选）     |
| love        | int      | 喜欢,默认为0        |
| comment     | text     | 批注，（可选）        |
| n~          | int      | 节点数量（后期用于加载优化） |
| create_time | datetime | 创建时间,自动生成      |
| change_time | datetime | 每次修改都更新，同样自动生成 |

+ node_relation 节点关联关系表

- 节点、思维导图、节点关联的增删改查接口完成
