| create_time | datetime | 创建时间,自动生成      | demo版不需要 |     |
| change_time | datetime | 每次修改都更新，同样自动生成 | demo版不需要 |     |

| comment     | text     | 批注             | 仅联机版需要   |     |

+ mind_map 思维导图表

| 字段          | 类型       | 备注             | 版本       |
| ----------- | -------- | -------------- | -------- |

多节点优化：现在初步规划时放思维导图表放一个数组存储每一层节点的数量，然后在节点表新增字段存储自身的层数，新增节点时只需要比父节点+1即可，同时席位导图数组同步更新。查询时根据层级数量过滤节点层级。
